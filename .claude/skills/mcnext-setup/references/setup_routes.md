# Proven setup routes (field-tested)

The route that worked for each step on a live org, end to end, in the order to run them. Paths are relative to the Setup host `https://<mydomain>.my.salesforce-setup.com` (sandbox: `<mydomain>--<sandbox>.sandbox.my.salesforce-setup.com`). Verify every step with the org's own data: `sf data query -o <alias> -q "..."` (strip ANSI codes and the CLI update-warning line before parsing `--json`). Never verify with an MCP connector unless you have proved it points at this org (see SKILL.md, Principles).

| Step | Route | Verify | Gotchas |
|---|---|---|---|
| S1 Org | `sf org display -o <alias>` | `SELECT IsSandbox, OrganizationType FROM Organization` | Demo/trial orgs return IsSandbox=false: proceed only if the intake says `demo_or_trial` and the user granted org trust |
| S2 Licences | CLI read | `SELECT MasterLabel, DeveloperName, UsedLicenses, TotalLicenses FROM PermissionSetLicense` | Look for MarketingCloudPsl, a Data Cloud PSL (e.g. GenieDataPlatformStarterPsl), CdpPsl. Missing = provisioning request, stop |
| S5 Permission sets | CLI read | `SELECT Name, Label FROM PermissionSet WHERE Label LIKE '%Marketing Cloud%' OR Label LIKE '%Data Cloud%'` | API names seen: MarketingCloudAdmin, MarketingCloudManager, GenieAdmin (= Data Cloud Architect), CDPAdmin (= Data Cloud Admin) |
| S6 Assign | `sf org assign permsetlicense -n MarketingCloudPsl -o <alias>`; `-n CdpPsl`; then `sf org assign permset -n GenieAdmin -n MarketingCloudAdmin -n CDPAdmin -o <alias>` | `SELECT PermissionSet.Name FROM PermissionSetAssignment WHERE AssigneeId = '<user id>'` | Licence before permission set. Reload Chrome after assigning |
| S3 Data 360 | CLI: `sf project retrieve start -m "Settings:CustomerDataPlatform"`, set `enableCustomerDataPlatform` to true, dry-run, deploy. UI alternative: `/lightning/setup/CDPSetupHome/home` > Get Started | `SELECT Name FROM DataSpace` returns `default`; CDPSetupHome tracker all green | Enabling via metadata starts provisioning but the tracker can sit at step 3 of 6 for 15-30 min, then completes on its own. Long job: leave `running`. Capital `CDP` in the URL (lowercase 404s). A retrieve overwrites a local prepared file: re-set the value before deploying |
| S4 CRM streams | Usually pre-existing in demo orgs. Else Data Cloud app > Data Streams > New > Salesforce CRM > Sales bundle (or objects individually for custom objects) | `SELECT Name FROM DataStream ORDER BY Name` shows Account_Home, Contact_Home, Lead_Home, Opportunity_Home, OpportunityContactRole_Home, User_Home | Data Streams list views under-report: trust SOQL |
| S21 Custom mapping | Data Stream record > Data Mapping > Start | DMO row count via SOQL | Skip when the org has no custom-object streams |
| S7 Basic Settings | `/lightning/setup/UnifiedMarketingBasicSettings/home`: work down the checklist; "Try Again" on a failed item | Items green; `SELECT Name FROM CommSubscription` returns `Marketing` | Enable Marketing Cloud starts automatically when the data space is confirmed (S9). A "Give us a minute" widget can stay loading after completion: trust the checklist and CommSubscription |
| S15 Data protection | Basic Settings item | Item shows Completed | Often already complete; if not, the heading is a status indicator only |
| S9 Data space | Basic Settings > Select a Data Space > `default` > Confirm (permanent) | Checklist item green | **Empty picker** has two causes, check both: (1) Data 360 provisioning still running (see S3); (2) data space not granted to the permission sets. Fix (2): Setup > Permission Sets > MarketingCloudAdmin / GenieAdmin / CDPAdmin > "Data Cloud Data Space Management" > tick `default` > Save (classic iframe page, see playbook). Greyed-out picker = missing Marketing Cloud Admin |
| S8 Data kits | Basic Settings > Deploy Data Streams > one "Deploy" button for all kits | All kit rows "Deployed"; `SELECT COUNT() FROM DataStream` grows (kit streams like MessagingConsent, EmailEngagement appear) | Up to 30-75 min. Rows show stale placeholders for ~10 s after each reload |
| S10 Identity resolution | Basic Settings > Generate Ruleset (enabled once most kits deploy) > confirm. **Then** Data Cloud app > Identity Resolution > open the ruleset > **Run Ruleset** | `SELECT COUNT() FROM UnifiedIndividual__dlm` > 0 (read the exact DMO name from Basic Settings; it can carry a ruleset suffix) | "Generate" only publishes the ruleset: Basic Settings shows Success with 0 unified rows until you Run it. The confirm dialog always mentions MCE data; that is generic text |
| S11 Data Graph | Data Cloud app > Data Graphs > New > Start from Scratch > Standard. Primary: Unified Individual; related: Contact Point Email/Phone/Address, Unified Link Individual. Save and Build (30-min refresh). Then Assistant Home > Customer Engagement > Configure Basic Personalization > select it | Data Graphs list: Active, record count = unified profiles | Limits: 50 fields per object, 200 per graph. Edit only via row menu > Edit (clicking the name opens a read-only view) |
| S16 Set Up Email | `/lightning/setup/CompanyProfileInfo/home` > Edit: address **and Security Contact name, email, phone** (required on save). Then `/lightning/setup/UnifiedMarketingEmailChannel/home`: consent validation defaults, tick the self-tracked checklist boxes | `SELECT Street, City, State, PostalCode, Country FROM Organization` | Company Information is a classic iframe page. Some Set Up Email checkboxes are manual self-tracking, not detected |
| S13 Sending domain | `/lightning/setup/E360EmailAuthenticatedDomains/home` > Add Domain: dedicated subdomain (`e.<root>`), add From address, open "Manual DNS Record Information", copy every record to `out/setup/dns_records.md`. Activate only if the intake says so and the user confirms DNS is in place | Domain status | Truncated grid values: read each cell with `find`/`read_page`. DMARC sits in a second grid below. Validation up to 72 h |
| S22 Test consent | Consent Imports CSV for the intake's test recipient, or a Draft MessagingConsent flow | Consent status on the contact | Only when the intake gives a test recipient |
| S17 Einstein | Four separate pages: `/lightning/setup/UmaSto/home`, `/UmaEef/home`, `/UmaEes/home`, Metrics Guard via Set Up Email > Optional Setup. Enable each. Then edit the graph (row menu > Edit) and add Email Engagement Frequency / Score DMOs through the **Contact Point Email** source node | Each page shows Enabled (STO: In Progress, up to 72 h) | A toggle can look reverted after reload: click again, a "disable?" dialog means it is on (Cancel). Einstein DMOs attach to the plain Contact Point Email node, not the unified one |
| S18 Analytics | Setup > Marketing Cloud > Assisted Setup > Reporting and Optimization > Analytics. Seen: Marketing Performance Intelligence (`/lightning/setup/MarketingPerformance/home`) and Flow Performance (`/lightning/setup/FlowPerformance/home`: Install Data Cloud Integration, Install Analytics Workspace, Assign Permissions) | The product's own status tab: Status=Success, Task Overview N/N | Package names differ from older docs. Flow Performance's data space picker resets on reload: re-select before each Install |
| S19 Analytics access | Usually the "Assign Permissions" permission set (Tableau Next included app) covers it | `PermissionSetAssignment` for the analytics permission set and the marketing admin/manager users | There may be no folders to share at all |
| S20 Record page | Object Manager > Contact > Lightning Record Pages: clone the current page (never overwrite), add Privacy Consent Status, Data Cloud Profile Engagements, Data Cloud Profile Insights. Save. Activate only if the intake says so | New page listed | Insert components via the canvas "+" point, not drag. Profile Insights needs a Calculated Insight to render |
| S14 Flow types | Setup > Flows > New Flow gallery: search "Audience" and "On-Demand" | Types offered | Segment-triggered flow is now "Audience Flow". FlowDefinitionView has no MC-specific ProcessType until a flow exists |
| S12 MCE connector | Data Cloud Setup > Marketing Cloud Engagement > New: stop at the MCE login and hand back; after consent, pick BUs and bundles | MCE streams in SOQL DataStream | Only when the intake gives an MCE EID |
| S23 Test send | Single Email flow to the opted-in test recipient | Send record status | Only when the intake asks for it and the domain is active |

## No CLI route
No Metadata API type exists for Basic Settings / Enable Marketing Cloud, identity resolution rulesets or Data Graphs. `DataStreamDefinition` and `DataPackageKitDefinition` exist but need a UI-built template first. Those steps stay Chrome-only.
